Entry for the make.fun competition "Rejected Olympic Sports": one funny single-line rejected Olympic sport, 1 to 200 characters, a made-up event that sounds like a real broadcast
`main.py` writes the entry to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), validating the gate first, then reading
the file back to verify the written bytes match.

> Speed Napping: athletes race to fall asleep first. The heats were cancelled after the entire crowd joined in.

Why this entry: Speed Napping wins the pairwise rounds because it is a made-up event the Games could plausibly have turned down, it lands in one read with the twist at the end (the heats were cancelled because the crowd joined in), it sounds like a real event a broadcaster would have to explain with a straight face, every word earns its place, and it is quotable the same day. Backup: The 100-Metre Stare — two athletes glare at each other, first to blink loses, nobody has ever finished.
